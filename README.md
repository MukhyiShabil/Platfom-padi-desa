# Tugas RPL - Agricultural Management System

Struktur proyek untuk Tugas Rekayasa Perangkat Lunak (RPL).

## Struktur Folder
- `backend/` : Server API (Express.js, Prisma ORM, Controllers, Services, Routes)
- `pages/` : Halaman HTML (Index, Login, Dashboard)
- `css/` : Styling stylesheet
- `js/` : Script client-side (API helper, Auth, Dashboard logic)
- `assets/` : File gambar dan media
